Send what your Collector found

It takes a minute. Your file is read here in your browser, and nothing is sent until you post it yourself.

1

Find your Collector file

Log out or type /reload first, so the game saves it. Then open this folder:

World of Warcraft\_forever_\WTF\Account\YOUR ACCOUNT\SavedVariables

The file is called NorgannonDBCollector.lua. It holds only what the Collector saw in the world: no character names, and nothing about other players. If you switched on /ndbc api, it also holds how the game's functions behaved, which goes to the Forever API reference for add-on authors.
